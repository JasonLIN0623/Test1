# Red vs Blue Last Ball Standing

這是一個參考「紅隊 vs 藍隊最後存活球」概念做出的 Canvas 小遊戲第一版。

## 目前功能

- 紅隊與藍隊球體自動追擊、移動與反彈
- 可切換團體戰與個人戰
- 團體戰是多顆紅球對多顆藍球，個人戰是 1 對 1
- 圓形競技場邊界
- 敵隊互相碰撞只會反彈，不會扣血
- 場地隨機生成武器、齒輪與加速器道具
- 場地道具會在 10 秒後消失
- 球體不會主動轉向撿道具，主要靠慣性、碰撞與後座力改變方向
- 手槍、散彈槍、狙擊槍、機關槍會讓球自動遠距攻擊
- 球拿到槍枝後，槍口會朝目前瞄準的敵人旋轉
- 球拿到武器後需要 1 秒準備時間才會射擊
- 武器射擊時會產生後座力，把球往反方向推開
- 撿道具、射擊、命中、護盾與勝利都有音效，射擊改為較接近真實槍聲的合成音效
- 齒輪可以讓球免疫一次武器傷害
- 隊伍血量條、存活數量與計時
- 最後存活隊伍勝利
- 可調整每隊球數與遊戲速度

## 道具說明

- 狙擊槍圖示：長槍管與瞄準鏡，只能射 1 發，精準度高
- 手槍圖示：短槍管與棕色握把，可以射 3 發，精準度低
- 散彈槍圖示：長槍身與槍托，可以射 2 發，精準度中
- 機關槍圖示：長槍身與彈匣，可以連射 5 發，精準度極低
- 齒輪圖示：獲得一次免傷護盾
- 加速器圖示：短時間提升球體速度

## 如何開啟

直接用瀏覽器開啟 `index.html`。

也可以用本機伺服器開啟：

```bash
cd /Users/linchuanxuan/Desktop/個人資料整理/11_程式開發專案/game-2
python3 -m http.server 8000
```

然後打開：

```text
http://127.0.0.1:8000/
```

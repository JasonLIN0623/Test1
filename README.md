# Red vs Blue Last Ball Standing

這是一個參考「紅隊 vs 藍隊最後存活球」概念做出的 Canvas 小遊戲第一版。

## 目前功能

- 紅隊與藍隊球體自動追擊、移動與反彈
- 圓形競技場邊界
- 敵隊碰撞後扣血與粒子效果
- 隊伍血量條、存活數量與計時
- 最後存活隊伍勝利
- 可調整每隊球數與遊戲速度

## 如何開啟

直接用瀏覽器開啟 `index.html`。

也可以用本機伺服器開啟：

```bash
cd /Users/linchuanxuan/Desktop/個人資料整理/11_程式開發專案/game-2
python3 -m http.server 8000
```

然後打開：

```text
http://127.0.0.1:8000/
```

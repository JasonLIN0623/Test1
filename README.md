# Red vs Blue Last Ball Standing

這是一個參考「紅隊 vs 藍隊最後存活球」概念做出的 Canvas 小遊戲第一版。

## 目前功能

- 紅隊與藍隊球體自動追擊、移動與反彈
- 可切換團體戰與個人戰
- 團體戰是多顆紅球對多顆藍球，個人戰是 1 對 1
- 新增房間戰：四隊大型室內地圖，有四角房間、彩色牆線與中央迷宮通道
- 房間戰中牆壁會阻擋視線，躲在後方時不會被瞄準
- 房間戰角色有簡單自我意識：看見敵人會接近或拉距離，看不見敵人會沿路線推進與巡邏
- 房間戰地圖改成方形格線迷宮配置，四角有房間，中央用彩色短牆形成多路線障礙
- 房間戰主畫面改為 Three.js 3D 斜視地圖，接近立體 CQB 沙盤視角
- 若瀏覽器不支援 WebGL，房間戰會自動退回原本 2D 地圖，避免畫面空白
- 房間戰 AI 會使用內部突入路線與 waypoint 自主推進，不需要玩家手動畫路線
- 角色到達關鍵點會短暫停頓掃角，再繼續推進，讓對抗更接近 CQB 搜索節奏
- 房間戰分成紅、藍、綠、金四隊，四隊會分別從地圖四個角落出發
- 房間戰改為 CQB 式移動，球體之間不再用碰撞互相彈開
- 房間戰目前取消門板，改用固定牆線做出類似 2D CQB 練習圖的配置
- 房間戰角色開局就會配發武器，不再以滿場撿槍為主要流程
- 房間戰各隊會分成多條 CQB 突入路線推進，角色會保持隊形偏移，不會全部擠到同一點
- 房間戰不再自動生成場上武器，角色開局即持槍
- 房間戰射擊不消耗彈藥，拿到槍後可持續射擊
- 房間戰不再因我方數量低於敵方而躲藏，會持續依路線推進或交戰
- 房間戰 AI 已整理成穩定行動狀態，並加入中繼點避障與卡住停止/重選路，會降低反覆換目標、亂轉向與貼牆抖動
- 房間戰主畫面已降低目標線、粒子與滿血血條干擾
- 房間戰使用俯視圖角色與武器圖片，角色會顯示隊伍色臂章與外圈，團體戰與個人戰仍維持球體外觀
- 新增紅、藍、綠、金四隊視角，小畫面只顯示該隊目前看得到的敵人與道具
- 圓形競技場邊界
- 敵隊互相碰撞只會反彈，不會扣血
- 場地隨機生成武器、齒輪與加速器道具，房間戰改為開局配槍且不再生成場上武器
- 場地道具會在 10 秒後消失
- 球體不會主動轉向撿道具，主要靠慣性、碰撞與後座力改變方向
- 手槍、散彈槍、狙擊槍、機關槍會讓球自動遠距攻擊
- 球拿到槍枝後，槍口會朝目前瞄準的敵人旋轉
- 球拿到武器後需要 1 秒準備時間才會射擊
- 團體戰與個人戰武器射擊時會產生後座力，房間戰射擊不影響角色移動
- 撿道具、射擊、命中、護盾與勝利都有音效，射擊使用下載的真實槍聲音檔
- 齒輪可以讓球免疫一次武器傷害
- 隊伍血量條、存活數量與計時
- 最後存活隊伍勝利
- 可調整每隊球數與遊戲速度

## 道具說明

- 狙擊槍圖示：長槍管與瞄準鏡，只能射 1 發，精準度高
- 手槍圖示：短槍管與棕色握把，可以射 3 發，精準度低
- 散彈槍圖示：長槍身與槍托，可以射 2 發，精準度中
- 機關槍圖示：長槍身與彈匣，可以連射 5 發，精準度極低
- 齒輪圖示：獲得一次免傷護盾
- 加速器圖示：短時間提升球體速度，僅出現在團體戰與個人戰

## 如何開啟

建議用 GitHub Pages 或本機伺服器開啟，這樣 Three.js、真實槍聲音檔才能穩定載入。

```bash
cd /Users/linchuanxuan/Desktop/個人資料整理/11_程式開發專案/game-2
python3 -m http.server 8000
```

然後打開：

```text
http://127.0.0.1:8000/
```

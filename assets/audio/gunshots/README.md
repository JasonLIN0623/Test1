# Gunshot Sound Assets

Source: OpenGameArt - Gunshot Sounds
https://opengameart.org/content/gunshot-sounds

Downloaded file:
https://opengameart.org/sites/default/files/sounds.zip

Original author shown in bundled license file: Vincent Sevedge.

The OpenGameArt page currently lists this asset as CC0, but the downloaded archive includes a Creative Commons Attribution 3.0 note. This project keeps the bundled `source-license.txt` and credits the original author to follow the stricter notice.

Files used:

- `pistol.wav` from `cz.wav`
- `shotgun.wav` from `shotty.wav`
- `sniper.wav` from `mosin.wav`
- `machine-gun.wav` from `sks.wav`
